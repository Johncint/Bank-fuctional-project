# Java Banking System

A console-based Banking System built in Java to demonstrate core Object-Oriented Programming (OOP) principles, featuring distinct account types, transaction fees, and interest calculations.

## Features
- **Multiple Account Types:** Basic, Savings, and Checking accounts.
- **OOP Concepts Applied:** Inheritance, Polymorphism, and Encapsulation.
- **Dynamic Operations:** Create accounts, deposit, withdraw, and apply interest.
- **Custom Rules:** Checking accounts apply a transaction fee, while Savings accounts can accrue interest.
- **Input Validation:** Handles incorrect inputs gracefully without crashing.

## How to Run
1. Make sure you have Java installed.
2. Compile the code:
   ```bash
   javac Main.java
